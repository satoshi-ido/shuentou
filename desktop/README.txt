終焉燈

■ 起動のしかた
このフォルダの中の Shuentou.exe をダブルクリックしてください。
インストールやネットワーク接続は必要ありません。

■ 「Windows によって PC が保護されました」と表示された場合
この実行ファイルには電子署名がないため、初回の起動時に Windows がこの警告を出すことがあります。
1. 警告の画面で「詳細情報」を押してください。
2. 表示される「実行」ボタンを押してください。
2回目以降の起動では、この警告は出ません。

■ ZIP から直接起動しないでください
ZIP を開いた画面から Shuentou.exe を起動すると、動かない場合があります。
ZIP を右クリックして「すべて展開」を選び、展開したフォルダの中から起動してください。

■ セーブデータ
セーブデータと設定は、Windows のユーザーごとのアプリケーションデータの領域に保存されます。
このフォルダを移動したり削除したりしても、セーブデータは残ります。
